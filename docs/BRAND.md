# Axioden identity

The requested provisional name Axiom has obvious direct product conflicts with
[AxiomAI](https://axiom.stream/downloads), an AI desktop application, and
[Axiom Studio](https://axiomstudio.dev/), an AI coding environment. Under the user's
authorization to select an alternative, this project uses **Axioden** provisionally.
An exact-name web check on 2026-10-30 found no obvious competing AI desktop product.
This is a product naming check, not trademark clearance.

The native display name, main window and executable are Axioden/axioden.
`local.ai-harness.desktop`, private package scopes, credential service names and
storage schemas retain their stable identifiers. No data-directory migration is
needed because application identity is unchanged. Existing conversations and keys
stay in their existing locations. Versioned conversation export format remains
`ai-harness-conversation` for compatibility.

The original master icon was generated with the built-in image-generation tool,
then converted with the official Tauri icon command. Master:
`assets/brand/axioden-master.png`. Derived native formats are in
`apps/desktop/src-tauri/icons`; the UI uses a 256-pixel derivative. Mobile icon
formats are generated assets only; mobile builds have not been qualified.

Generation prompt: “Use case: logo-brand. Asset type: high-resolution master icon
for Axioden, a premium developer-focused personal AI workstation. Create one
original minimal geometric symbol, a precise interlocking pair of angular folded
paths forming a balanced open central diamond, clearly recognizable at 16px. Flat
vector-like geometry with strong silhouette, generous negative space, restrained
mint-teal and pale ivory on a deep ink rounded-square tile. The symbol is centered
with comfortable inset. Crisp edges, no hairlines, no gradients, no glow, no glossy
3D or shadows. No letters, no text, no watermark, no copied AI-company marks.
Square 1024x1024 or higher master suitable for desktop taskbar, dock and app UI,
attractive against light and dark desktop backgrounds.”

The generated result has been inspected. Taskbar/titlebar/installer qualification
must be recorded separately from asset generation and conversion.
