# Provider connections

Reviewed 2026-10-27. Open Connections, choose a billing method, authenticate, refresh discovery, and select a returned model near the composer. Discovery confirms account visibility; a completed response separately verifies inference access. No default model or static fallback catalog is used. Failed model access is surfaced explicitly.

- **ChatGPT plan:** Continue with ChatGPT opens official browser authorization. The app uses its own dynamically registered identity, PKCE, state, nonce, validated identity tokens, refresh tokens, and a stable installation host ID. A temporary loopback listener closes after authorization. Responses send full conversation context with `store:false` and streaming enabled. See [official sign-in](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), [models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference), and [preview restrictions](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations). Availability depends on the account and preview policy.
- **OpenAI API:** supply an official API key. API usage has separate billing from ChatGPT subscriptions. Authenticated Models API discovery filters for supported text-chat families. See [OpenAI API](https://platform.openai.com/docs/api-reference/models).
- **Claude plan:** install the official Claude client, run `claude auth login`, and explicitly provide its absolute executable path. Existing client authentication stays with that client. The official Agent SDK uses a fresh chat-only query with labelled conversation context, no tools, MCP, hooks, Skills, project settings, or session persistence. API-key overrides are excluded. Missing or signed-out clients must be configured outside this app, or use the Anthropic API connection. See [subscription guidance](https://support.claude.com/en/articles/15036540-use-the-claude-agent-sdk-with-your-claude-plan) and [SDK restrictions](https://code.claude.com/docs/en/agent-sdk/overview).
- **Anthropic API:** supply an official API key; discovery uses the paginated Models API. API billing is separate from Claude plan usage. See [Models API](https://docs.anthropic.com/en/api/models-list).
- **Gemini API:** use an official API key and its applicable project quotas/billing. Discovery includes models supporting text generation. Gemini CLI OAuth credentials are not reused. See [Models API](https://ai.google.dev/api/models) and [CLI guidance](https://geminicli.com/docs/resources/faq/).
- **xAI API:** use an official API key and account language-model discovery. API usage is separately billed from consumer Grok subscriptions. See [billing guidance](https://docs.x.ai/console/faq/accounts).

Secure storage requires a running, unlocked Linux Secret Service (for example GNOME Keyring or a compatible KDE setup). If unavailable, explicitly choose session-only storage; those credentials disappear on exit. Disconnect removes the app-owned saved connection. This does not revoke permissions at the provider; manage grants in the provider account as needed.

OpenRouter, Ollama, LM Studio, and custom endpoint factories remain available as extension boundaries, without connection screens in this milestone. No provider keys are required for automated checks. Live acceptance has been completed for ChatGPT subscription only; the remaining connections require independent account-specific verification.
